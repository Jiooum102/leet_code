## How to configure and run

1. Install CMake (https://cmake.org/download/)
2. Install a C++ compiler (e.g., g++, clang)
3. In the project root directory, run:
   ```sh
   cmake -S . -B build
   cmake --build build
   ```
4. Executables will be in the `build` directory. Run any executable, e.g.:
   ```sh
   ./build/HelloWorld
   ./build/problem_1_p1
   ```

## CLion Setup

1. Open CLion and select "Open".
2. Choose the root directory of this project.
3. CLion will automatically detect the CMakeLists.txt and configure the project.
4. You can build and run any executable directly from the CLion interface.
